# Pokédex

Projeto de uma Pokédex desenvolvido durante as aulas da **Digital Innovation One (DIO)**, com foco na prática de HTML, CSS, JavaScript e consumo de APIs.

## Sobre o projeto

A aplicação apresenta uma listagem de Pokémon em uma interface web, permitindo explorar diferentes Pokémon e carregar mais resultados conforme a navegação.

O projeto foi desenvolvido para colocar em prática conceitos de desenvolvimento web e integração com APIs.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- API de Pokémon

## Funcionalidades

- Listagem de Pokémon
- Carregamento dinâmico de conteúdo
- Botão para carregar mais Pokémon

## Como executar

1. Clone o repositório:

   `git clone https://github.com/elvisondev/Pokedex.git`

2. Abra a pasta do projeto no VS Code.
3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server.

## Objetivo

Praticar a manipulação do DOM, a organização de arquivos JavaScript, o consumo de APIs e a construção de interfaces web.
